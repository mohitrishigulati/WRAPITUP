# WrapItUp

Next.js 14 e-commerce (catalog, cart, Stripe checkout, account, admin, verified reviews).

**Full documentation:** [docs/WRAPITUP-COMPLETE.md](docs/WRAPITUP-COMPLETE.md)

## Getting Started

```bash
cp .env.example .env
npm install
npm run db:migrate
npm run db:seed
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

See [docs/WRAPITUP-COMPLETE.md](docs/WRAPITUP-COMPLETE.md) for environment variables, security checklist, API routes, and production deployment.
